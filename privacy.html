Timekoi

Privacy policy

This policy covers the Timekoi browser extension test build. Last updated 25 November 2026.

Timekoi is family screen-time and web-filtering software for Windows, published by Alien Frost Software.

What the extension handles

The web addresses of pages opened in Chrome on a computer where a parent has installed Timekoi.

What it does with them

It sends each address to the Timekoi app on the same computer. The app checks the address against the rules the parent set, and records it so the parent can see the child's browsing history on that computer. The extension doesn't read or change the content of web pages.

Where data goes

In this test build, browsing data stays on the computer. It is not sent to Alien Frost Software or anyone else, not sold, and not used for advertising.
